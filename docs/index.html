github-launch-skill

Agent Skill that launches your project onto GitHub.

把你的项目上架到 GitHub 的 Agent Skill。编码代理写好双语 README、About、许可证、CI 和 Pages 落地页，并交出检查清单。它不拦截 git push。

Say ship this to GitHub, 上架 GitHub, or 准备开源. The agent follows the skill and edits the target repository. This page does not turn GitHub Pages on. Enable it under Settings → Pages → Deploy from a branch → /docs.

What it writes

  • Project intake, then a review for secrets, personal data, dead demos, license headers, .gitignore, and large binaries
  • README.md and README.zh-CN.md
  • About description (160 characters or fewer) and 5–10 topics
  • MIT by default; Apache-2.0 or AGPL-3.0 when you ask
  • A short GitHub Actions workflow, llms.txt, and this kind of landing page

Install

git clone https://github.com/loomlab-ai/github-launch-skill.git
mkdir -p .cursor/skills
cp -R github-launch-skill/skills/github-launch .cursor/skills/github-launch
