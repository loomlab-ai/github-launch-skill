# Contributing

Issues and pull requests are welcome.

- Edit files under `templates/`, then run `python3 scripts/check_kit.py --sync-assets` so `skills/github-launch/assets/` stays a byte copy.
- Change `README.md` and `README.zh-CN.md` in the same pull request. Same section order, same commands, same URLs.
- Run `python3 scripts/check_kit.py` before you push.
- Do not add personal names, phone numbers, or employer details. Public contact for this repository stays the GitHub org, the published email, GitHub Sponsors, and the published X account.
- Do not link a website that is not this GitHub organization. `loomlab-ai` on GitHub is the org; do not point at an unrelated product domain.
- License text stays MIT. Change the copyright line only if LoomLab asks for that. Do not reword the permission grant.
